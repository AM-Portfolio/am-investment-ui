## How to Download Logos

1. **Right-click method**: 
   - Visit the broker's website
   - Right-click on their logo
   - Select "Save image as..." or "Copy image address"
   - Save as PNG format

2. **Browser developer tools**:
   - Press F12 to open developer tools
   - Use the element selector to find the logo image
   - Right-click on the image URL and save

3. **Logo download sites**:
   - You can also search for official broker logos on sites like:
     - Wikimedia Commons
     - Company press kit pages
     - Logo databases

## Image Requirements

- **Format**: PNG with transparent background preferred
- **Size**: Minimum 100x100px, maximum 500x500px
- **Quality**: High resolution, crisp and clear
- **Background**: Transparent or white background
- **Aspect Ratio**: Square (1:1) preferred

## After Downloading

1. Place all downloaded images in: `assets/images/brokers/`
2. Ensure file names match exactly (case-sensitive):
   - zerodha.png
   - angel.png
   - upstox.png
   - icici.png
   - hdfc.png
   - kotak.png
   - sbi.png
   - sharekhan.png
   - motilal.png
   - edelweiss.png
   - fyers.png
   - alice.png

3. Run `flutter clean` and `flutter pub get` after adding the images
4. Test the app to ensure all logos display correctly

## Fallback

If you cannot find a specific broker's logo, the app will automatically fall back to a branded icon with the broker's color scheme, so the app will still work properly.
